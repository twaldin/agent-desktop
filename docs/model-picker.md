# Searchable model selection

Source 11 replaces the composer's and native Session model control's unsearchable native menus. Installed release 10 exposed roughly 4,900 entries. This change does not alter native model resolution, available providers, credential ownership or admission rules.

The shared picker searches provider, display name, model ID and displayed metadata. Duplicate names retain distinct provider identities. Current selection appears first; the first 100 rows load initially with an explicit full count and more-results action. Search examines the entire catalog. Disabled choices remain visible and cannot be submitted; an unavailable model remains selectable in native Settings where the previous control allowed that native operation. Default/current-session intent and saved draft selections retain their existing meanings.

A native dialog provides focus containment. Search supports arrows, page movement and Enter, skips disabled entries, and ignores composition Enter. Escape or outside dismissal closes without changing the choice; selection restores trigger focus. Disconnect closes the menu and disables its trigger. Placement and scrolling stay within the actual viewport, including narrow windows and zoom. The component uses existing theme surfaces, fonts, radius and color tokens.

Validation: 24 focused model/composer/settings tests passed with 2,062 assertions; typecheck passed. The production component also passed five actual Electron DOM scenario groups using a controlled 4,902-option catalog. These cover full-catalog search, paging, duplicate identities, disabled/empty results, composition, keyboard/focus, disconnect and follow-current selection. Private result and rendered 1000×820/420×600 captures are under `.data/model-picker-source11/`; the smaller window used 120% zoom. Visual inspection confirmed readable rows and contained layout. Events in this fixture are programmatic; installed native input, real catalog selection and matching reference menus still require their separate acceptance checks.

Installed Home 11 subsequently passed native CUA search and Return against its real 4,900-entry catalog. Selecting 5.5 changed only the draft, while its session stayed idle on mini. Follow-current cleared the override; the original mini selection/text/project/thinking values were restored. This invoked no provider. Evidence is `.data/ui-acceptance/release11-model-override.json` and `release11-model-follow-current.json`. Native Settings picker selection, the broader installed geometry/keyboard matrix and reference menu comparison remain distinct checks.
